## О проекте

Проект посвящён созданию сервиса тактического планирования в футболе, использующего обучение с подкреплением для поиска и оценки решений в моделируемых игровых ситуациях.

В основе подхода лежит взаимодействие обучаемого агента с игровой средой. На каждом шаге агент получает описание ситуации, выбирает действие и получает награду, отражающую полезность этого действия с точки зрения заданной тактической цели.

Сервис предполагает объединение трёх компонентов:

1. **Игровая среда** — моделирование футбольных ситуаций и переходов между состояниями.
2. **RL-агент** — обучение стратегии выбора действий и оценка её поведения.
3. **Интерфейс анализа** — настройка экспериментов, визуализация игровых эпизодов и сравнение результатов.

Проект ориентирован на исследовательскую и учебную задачу. Результаты моделирования не следует трактовать как гарантированно оптимальную тактику для реальных матчей.

## Концепция обучения с подкреплением

### Состояние

В упрощённом варианте состояние среды может включать:

- координаты мяча;
- координаты игроков атакующей и обороняющейся команд;
- сторону, владеющую мячом;
- расстояния до ворот и ближайших соперников;
- дополнительные признаки игровой ситуации.

Конкретное представление состояния определяется выбранным сценарием и доступными данными.

### Действия

Для начального прототипа можно рассмотреть ограниченный набор действий:

- передача выбранному партнёру;
- продвижение с мячом;
- удар по воротам;
- завершение эпизода или безопасное действие, если это предусмотрено правилами среды.

Состав действий должен соответствовать тому, какие переходы действительно реализованы симулятором. Если моделируются только отдельные игроки, это необходимо явно указать.

### Функция вознаграждения

Функция вознаграждения задаёт желаемое поведение агента. В качестве отправной точки можно учитывать:

- положительную награду за гол или создание опасной ситуации;
- небольшую награду за успешное продвижение;
- штраф за потерю мяча;
- штраф за неудачное действие, если оно снижает вероятность достижения цели.

Численные значения наград должны подбираться и проверяться экспериментально. Необходимо следить за нежелательным поведением, возникающим из-за слишком простой функции вознаграждения.

### Алгоритм

В качестве первого кандидата можно использовать **PPO (Proximal Policy Optimization)** из Stable-Baselines3. Выбор алгоритма окончательно определяется типом пространства действий, устройством среды и результатами экспериментов.

Важно: использование исторических матчей и обучение с подкреплением — разные этапы. Исторические данные могут помогать строить сценарии или обучать начальную политику, но интерактивное RL-обучение требует среды, которая возвращает новые состояния и награды в ответ на действия агента.

## Оценка качества

Одной суммарной награды недостаточно для вывода о тактическом качестве. Рекомендуется использовать несколько метрик:

| Метрика | Что показывает |
|---|---|
| Средняя суммарная награда | Насколько хорошо агент выполняет заданную функцию вознаграждения |
| Доля эпизодов, завершившихся голом | Результативность в сценариях, где гол является целью |
| Доля успешных передач | Надёжность передач, если они моделируются |
| Частота потери мяча | Риск при выборе действий |
| Время до достижения цели | Эффективность, если длительность эпизода имеет значение |
| Сравнение с базовой стратегией | Даёт ли обучение улучшение относительно случайного или эвристического агента |

Метрики применяются только тогда, когда соответствующие события и правила определены в среде. Для честного сравнения стратегии нужно тестировать на одинаковых наборах сценариев и, по возможности, на нескольких случайных seed. Следует приводить не только среднее значение, но и разброс результатов.
